# Experimental Results

The folder name is in this format: `[helper-model_target-model_judge-model_num-of-prompts]`.

For example, `kimi-k2_claude-3-5-haiku_deepseek-v3_5` saves the jailbreaking attack logs of this setting:

```python
helper model: kimi-k2
target model: claude-3-5-haiku
judge model: deepseek-v3_5
num-of-prompts: 5
```
